# 홈택스·위택스 제출 절차 (어사이드, 양도세·증여세 공용)

2026-10-26 상가·오피스텔 부담부증여 건(양도세 1건 + 위택스 지방소득세 1건 + 증여세 4건 + 부속서류 4건)을 실제로 낸 순서와, 그때 확인한 화면 특성입니다. 홈택스 CLI가 나오기 전까지는 이 문서대로 **어사이드**(`mcp__aside__repl`)로 합니다. 사무소 공통 규칙은 `위하고-홈택스-어사이드` 스킬을 먼저 읽습니다.

## 0. 원칙

| 누가 | 무엇을 |
|---|---|
| 사용자 | 홈택스 인증서 로그인, **주민등록번호 입력**(조회 칸 포함), 위택스 실명인증·주소검색·자동입력방지, 비밀번호 |
| 에이전트 | 메뉴 이동, 파일 선택·검증, 결과 읽기, PDF 저장, 사용자가 「바로 제출」로 지시한 경우의 제출 버튼 |

- 주민등록번호는 사용자가 허락해도 에이전트가 칸에 넣지 않는다. 번호가 있는 파일(신고인.json)의 위치만 알려 준다.
- 제출 버튼(전자파일 제출하기, 위택스 제출, 부속서류 제출하기)은 그 회차 지시에 「제출」이 있을 때만 누른다. 없으면 직전에서 멈추고 보고한다.
- 어사이드는 **세션 폴더 밖 파일을 올리지 못한다**("escapes the session directory"). repl 의 `pwd`(예: `C:\Users\<사용자>\.aside\u\0\sessions\2026-10-26_xxxx`) 아래 `upload\` 로 먼저 복사한다. 부속서류는 `scripts/hometax_attach.py` 가 복사·합본까지 해 준다.
- 다운로드(PDF 저장)도 `pwd\upload\` 에 받은 뒤 작업 폴더 `신고완료_접수증_납부서\` 로 옮긴다.
- 홈택스 세션은 30분쯤 지나면 끊긴다. 화면이 「국세청 홈택스 - 메인」(로그인 링크)으로 돌아가거나 메뉴에서 로그인 화면이 뜨면 아무것도 제출되지 않은 것이다 — 사용자에게 다시 로그인을 요청하고 그 단계부터 다시 한다.

### 어사이드 repl 요령

- repl 변수는 호출 사이에 남는다. `const` 이름을 호출마다 새로 짓는다(같은 이름이면 SyntaxError).
- 홈택스는 WebSquare 라 `input[type=file]` 이 없다. 「파일선택」 버튼을 누르면서 `page.waitForEvent('filechooser')` 로 받아 `setFiles()` 한다.
- `ref`(e123)는 snapshot 마다 바뀔 수 있다. 누르기 직전 snapshot 트리에서 `button "이름" [ref=(e\d+)]` 정규식으로 찾는다. `getByRole('button',{name})` 은 WebSquare 버튼을 못 찾는 때가 많다.
- 팝업 창(부속서류 첨부, 제출내역)은 `tabs` 에 바로 안 잡힐 수 있다. `listBrowserTabs()` 로 url(`UTERNAAZ42` 첨부, `UTERNAAZ40` 제출내역)을 찾아 `attachBrowserTab(targetId)`.
- 접수증·납부서는 `sesw.hometax.go.kr/serp/clipreport.do` 새 탭(리포트)으로 열린다. 여러 개가 열리면 탭 순서가 섞이므로 **본문 내용(접수번호·성명)으로** 어느 리포트인지 고른다.

```js
// 공용 도우미 (한 번 정의)
const ref = (tree, re) => { const m = tree.match(re); return m ? m[1] : null; };
globalThis.findReport = async (kw) => { for (let i=0;i<25;i++){ await sleep(1000);
  for (const t of tabs.slice().reverse()) { if (!t.url().includes('clipreport')) continue; let x='';
    try { x = await t.evaluate(()=>document.body.innerText.replace(/\s+/g,'')); } catch(e){}
    if (kw.every(k=>x.includes(k))) return t; } } return null; };
globalThis.saveReport = async (rpt, path) => {           // clipreport: 「PDF 저장」 → 바로 다운로드, 안 되면 옵션 창 「저장」
  await sleep(4000); let s = await snapshot(rpt,{interactive:true});
  const b = ref(s.tree, /button "PDF 저장" \[ref=(e\d+)\]/) || ref(s.tree, /button "저장" \[ref=(e\d+)\]/);
  let dP = rpt.waitForEvent('download',{timeout:8000}).catch(()=>null); await rpt.locator(b).click(); let d = await dP;
  if (!d) { await sleep(1000); s = await snapshot(rpt,{interactive:true});
    const b2 = ref(s.tree, /button "저장" \[ref=(e\d+)\]\s*- button "취소"/);
    dP = rpt.waitForEvent('download',{timeout:20000}); await rpt.locator(b2).click(); d = await dP; }
  await d.saveAs(path); await closeTab(rpt).catch(()=>{}); return path; };
```

## 1. 전자신고 파일 제출(파일변환신고)

메뉴: 신고/납부 → 세금신고 → (양도소득세 | 증여세) → **파일변환신고**(링크 이름 「파일변환신고 회계프로그램」). 메뉴 검색창에 「파일변환신고」로 찾아도 된다.

1. 전자신고 파일(`*_C116300.01`, `*_G101500.01`)을 `pwd\upload\` 로 복사한다.
2. 「파일선택」 → filechooser 로 파일 지정. 「이미 검증이 완료된 자료가 존재합니다. 다시 하시겠습니까?」 알림이 뜨면 「확인」 뒤 다시 「파일선택」.
3. 「파일검증하기」 → 3초 간격으로 본문을 읽어 `[내용검증하기]가 완료` 가 나오고 `검증 중입니다` 가 없어질 때까지 기다린다(보통 10~30초).
4. 결과 줄 「형식검증 오류 납세자수 / 내용검증 오류납세자수 / 정상납세자수」를 읽는다.
   - 오류가 있으면 「전자제출이 가능한 자료가 존재하지 않습니다」. 오류 건수 링크 → 「신고서 오류내역 조회」 팝업에서 메시지를 읽고, 원인을 고쳐 파일을 다시 만든다(제출 안 함).
   - 정상이면 「정상자료확인」 팝업에서 성명·과세표준·실제납부할세액을 읽어 신고서 PDF 와 맞는지 본다 → 「닫기」.
5. (제출 지시가 있을 때) 「제출하러 가기」 → 「전자파일 제출하기」 → 알림 「정상 변환된 신고서를 제출합니다」 「확인」 → 「정상제출내용」 표에서 **접수번호·접수일시**를 읽어 기록한다.
6. 다음 파일: 제출 뒤 나오는 알림에서 「예」 → 「파일변환신고 회계프로그램」 링크로 돌아가 2부터.

확인한 내용검증 규칙:
- 증여세 10 레코드(임대보증금 채무) **임차기간 종료일 ≥ 증여일** 이어야 한다(「임차기간 종료일은 증여일보다 크거나 같아야 합니다」). 증여세 스킬 `make_return.py` 가 지난 계약을 묵시적 갱신 단위로 자동으로 늘리고 알림에 적는다.
- 양도세 부담부증여(신고유형 9)는 내용검증 오류 0 으로 접수됨.

## 2. 접수증·납부서 PDF 저장

메뉴: 같은 세목 화면 서브메뉴 **「신고내역 조회(접수증·납부서)」**.

- 조회 조건: 세무대리인 로그인이면 **주민등록번호 칸을 비우고 「당일」 → 「조회」만으로** 그날 낸 신고가 모두 나온다(2026-10-26 증여세 4건 확인). 메뉴를 누를 때 「계속 하시겠습니까?」가 뜨면 「예」. 안 나오면 사용자에게 주민등록번호 입력·조회를 요청한다.
  (「신고부속서류 제출」 화면은 주민등록번호가 필수 칸이라 이 방법이 안 된다.)
- 행마다: 「접수증 보기」 → 리포트 탭 → `findReport(['접수증', 접수번호])` → `saveReport(r, upload\<세목>_신고서접수증_<성명>.pdf)`.
- 납부서: 행의 「납부서」 → 납부서 목록 레이어 → 납부서 이미지(`image "납부서"`)를 누르면 리포트 탭 → `findReport(['영수증서', 성명])` → 저장 → `<세목>_납부서_<성명>.pdf`.
  여러 건을 연달아 누르면 리포트가 한꺼번에 열린다. 열린 리포트를 돌면서 본문에서 성명·납부기한·「계」 금액을 읽어 이름을 붙인다.
- 납부서 금액은 신고세액에서 **10원 미만을 버린 금액**이다(예: 145,382,815 → 145,382,810). 표로 보고할 때 두 금액을 함께 적는다.
- 저장한 PDF 는 작업 폴더 `<건>\신고완료_접수증_납부서\` 로 옮기고, 납세자에게 보낼 것은 바탕화면에 zip 으로 묶는다(주민번호는 리포트에서 이미 가려져 있음).

## 3. 위택스 지방소득세(양도소득분) — 양도세만

1. 신고내역 조회 행의 **「지방소득세」 「이동」** → 위택스 「양도소득분 예정신고」(`wetax.go.kr/etr/lit/b0703/B070301M02.do`) 새 탭.
2. 1단계 신고인: 신고인 유형 세무대리인 — 성명 세무대리인, 상호 (사무소명), 사업자등록번호 1234567890, 전화 0212345678(`efile/세무대리인.json`). 납세자 전화·휴대전화는 신고인 파일 값. **실명인증·주민번호·주소검색은 사용자**. 「인증성공」 확인 뒤 「다음」.
3. 2단계 신고기본정보: 행정동 콤보(예: 「OO동(행정동)」 — 법정동 OO동의 행정동)를 고른다. 양수인 자동입력방지·실명인증은 사용자.
4. 3·4단계(신고세액·산출세액): 국세 과세표준이 넘어와 있다. 과세표준·세율(예: 2.4%)·산출세액이 신고서 PDF 와 같은지 보고 「다음」.
5. 5단계 신고서제출: 동의 체크박스가 숨겨져 있어 `label[for="terms_agree_one01"]` 를 누른다 → 「제출」 → 6단계 「정상적으로 완료」 문구에서 납부(환급) 세액·납부기한을 읽는다(예정신고 지방소득세 기한 = 국세 예정신고기한 + 2개월, 예: 2027-03-31).
6. 「신고서 출력」·「납부서 출력」 → OZ 뷰어 새 탭(`ozhJsonviewers.oz`) → 「저장」 → 저장 창 「파일 형식」 콤보에서 **Adobe PDF File(*.pdf)** → 「확인/저장」 → 다운로드 → `지방소득세_신고서_<성명>.pdf`, `지방소득세_납부서_<성명>.pdf`.

## 4. 신고 부속서류(증빙) 제출

메뉴: 신고/납부(hover) → 신고삭제/부속서류 → **「신고부속서류 제출」**. (세목 화면의 「신고 부속·증빙서류 제출」 링크는 로그인 화면으로 튕기는 때가 있었다.)

1. 첨부 파일을 모은다: `python -I -X utf8 scripts/hometax_attach.py --이름 1_수증자A <파일들> [--합본 "임대차계약서_501~514호.pdf" <파일들>]`.
   - 한 번 「파일선택」에 **5개까지**, 한 번 제출 **50MB 까지**. 넘으면 같은 종류를 합본한다(5개를 넘겨 고르면 앞의 5개만 들어가고 나머지는 말없이 빠진다).
   - jpg·png 는 홈택스가 PDF 로 바꿔 받는다. 제출파일명 칸은 파일 이름(확장자 뺀 것)이 그대로 들어간다 — 파일 이름을 서류 이름으로 지어 둔다.
2. 세목 콤보 선택(증여세·양도소득세) → 「주민등록번호」 라디오 → **사용자가 번호 입력·조회**. 신고일자 기본값은 한 달 전~오늘.
3. 결과 행 본문을 읽어 **성명·신고서 접수번호**가 맞는지 확인 → 「첨부하기」 → 팝업(`UTERNAAZ42`, `listBrowserTabs` 로 찾기).
4. 팝업 「파일선택」 → filechooser 에 업로드 폴더의 파일 전부 → 표에 파일이 다 올라왔는지(개수·크기) 확인. 잘못 올렸으면 머리 체크박스 → 「삭제」.
5. (제출 지시가 있을 때) 「부속서류 제출하기」 → 팝업이 닫히고 행의 버튼이 「제출내역보기」로 바뀐다(따로 확인 알림 없음).
6. 확인: 「제출내역보기」 → 레이어 「부속서류 제출목록」에서 **부속서류접수번호·접수시각** → 「제출확인」 → 팝업(`UTERNAAZ40`)에서 첨부파일명 → 제출파일명(.pdf) 목록을 읽는다. 더 낼 것은 레이어의 「부속서류 추가 제출」.
7. 다음 사람은 사용자가 같은 화면에서 번호를 바꿔 조회해 준다.

제출 결과는 작업 폴더 검토 문서에 표(수증자/신고인, 신고서 접수번호, 부속서류 접수번호, 파일)로 남긴다.

## 5. 기록

- 제출을 마치면 고객 DB 상태를 「제출」로 바꾼다: `python scripts/client_db.py 상태 --고객번호 N --신고번호 <번호> --상태 제출`.
- 접수번호(신고서·부속서류·지방소득세)는 작업 폴더 검토 문서에 적는다.
